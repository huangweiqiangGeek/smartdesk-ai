# Agent 和 AI 服务边界

本项目第一版提供基于 FAQ/文本知识的自动接待，以及人工端翻译、会话摘要和回复草稿，不建立通用自主 Agent。自动回答候选由 NestJS 校验后发送，人工草稿由客服确认；产品规则见 [V1 PRD](prd-v1.md)。

## 职责矩阵

| 执行方 | 可以做 | 不可以做 |
| --- | --- | --- |
| NestJS service/worker | 验证权限、提供授权知识快照、安排任务、保存结果、校验自动回答准入、执行人工发送 | 将模型输出直接作为授权或 SQL |
| FastAPI AI 服务 | 调用推理/Embedding 模型、校验类型化输出、返回 usage 与错误 | 查写业务数据库、加入 Socket 房间、发送消息、修改工单 |
| 模型 | 基于给定知识生成回答候选、翻译、提炼摘要、草拟回复 | 自行选择租户、扩展上下文权限、执行任意工具 |
| 客服 | 查看/修改建议并明确发送 | 通过前端参数绕过服务端权限 |

LangGraph、MCP、多 Agent 和自主工具调用不进入第一版。以后确有需要时先定义业务价值、权限、预算和失败语义，再单独设计，不照搬 Agent Hub 的执行框架。

## 输入与输出

- 仅接收 NestJS worker 传入的已授权最小文本快照，含 taskId、operation、inputRevision、promptVersion 和必要语言信息；业务租户上下文由受认证的调用方提供，不能来自模型文本。
- 输入包含客户消息、客服消息和原文语言，明确角色边界。自动回答附当前已启用且就绪的知识片段、来源 ID/版本和会话状态版本；内部备注默认不进入自动回答或对客草稿上下文。聊天和知识文本不能覆盖服务规则。
- 输出必须匹配 operation 的 Schema：自动接待返回回答/澄清/建议交接类型、依据引用和理由；翻译返回原消息引用、目标语言和译文；摘要返回覆盖游标和正文；建议返回草稿。交接类型仅是候选，由 NestJS 按产品规则决定；禁止返回可直接执行的业务命令。
- 原文保持不可变，译文和摘要单独保存。提供方声称的 tenantId、senderId 或状态字段不参与授权或业务写入。
- 超过输入窗口时按明确策略截取连续会话片段，并返回覆盖范围；不把截取后的摘要冒充完整历史摘要。

## 异步与容错

- NestJS/BullMQ 是任务状态和跨服务重试的唯一 owner；FastAPI 单次调用有超时，不再另起队列或无界自动重试。
- 初始时间、Token 及重试预算以 [contracts.md](contracts.md) 为准。仅限流、暂时网络/提供方故障可重试；权限、Schema 和业务状态错误不重试。
- 已保存的 taskId 结果优先返回，重复消费不得生成重复业务记录。幂等是业务设计，不是只设置队列 jobId，参见 [BullMQ 幂等任务](https://docs.bullmq.io/patterns/idempotent-jobs)。
- AI 不可用时，正常消息仍先保存并确认，客服继续人工回复。界面明确辅助功能失败；不把失败内容填充成伪造的翻译或建议。
- 新消息或源文本修订使旧结果失去当前性；NestJS 保存前按 inputRevision 条件校验，过期结果标 superseded。每个任务固定自己的 Prompt/模型版本，不在重试中静默升级。
- 自动回答还受知识版本、启用状态、会话状态和 AI 开关约束；交接接受后迟到候选不发送。产品事实必须有有效依据，资料不足最多澄清一次，仍不足或冲突则交接，不用模型自报置信度替代这些规则。
- 自动接待等待上限含排队，起点与预算以 contracts 为准。AI 或队列失败不能让会话无限停在生成中；交接摘要失败不阻止接管。
- 客服本地编辑由前端 draftRevision 保护；前端对照发起任务时的草稿版本，拒绝自动回填到已修改草稿。服务端未收到本地编辑时，不能宣称已通过后端 inputRevision 检测到它。

## 自动回答、人工确认与上下文隐私

自动接待仅在会话仍为 AI 接待、输入与知识仍有效且输出满足准入时，由 NestJS 生成 AI 消息。客户端 AI 结果通知不触发发送；模型没有发送权限。转人工后只有内部辅助，不自动切回 AI。

AI 建议进入草稿区，只有客服明确发送才调用普通消息 service。发送时重新校验角色、会话状态和消息内容，不允许模型通过“send=true”等输出字段触发发送。

只向模型提供完成当前操作所需内容；使用哪些提供方、数据保留策略及是否发送真实客户数据，在部署配置与产品说明中确认。测试采用合成或获准数据。普通日志保留任务和用量元数据，不记录完整客户聊天。

## 评测

Prompt、模型、知识处理和截断策略变更时回放固定测试集：知识内问题、无依据/冲突、转人工、多语言、空输入、长会话、提示注入、提供方超时、无效 JSON、迟到结果和重复消费。自动回答检查依据与交接，翻译检查语义及专有名词，摘要检查事实及覆盖范围；回答与建议不能凭空承诺价格、退款或操作结果。样本分组和初始门槛见 PRD 第 12 节。

AI 质量评测与消息可靠性测试分别报告；模型能生成文本不代表产品闭环通过。验收标准见 [quality.md](quality.md)。

知识切片/检索、Q01—Q13 节点、一次澄清标记、版本/lease 发送裁决与评测执行见 [Agent 执行流程](ai-workflow-v1.md)；字段与内部端点分别见 [数据模型](data-model-v1.md) 和 [API](api-v1.md#5-ai-内部合同)。这些设计尚未运行，不构成模型效果证据。

## 1 执行规则与里程碑

一次 Codex 工作单只实施一个 T 编号；依赖未完成先核实，不用静态页面或全绿 mock 掩盖缺项。同一任务可分为服务端合同、实现、界面、验证等小步，但必须完成本任务的垂直链路后才能标完成。需要修改任务范围时先说明具体差异，普通局部实现选择不反复请求批准。

| 里程碑 | 包含任务 | 可观察出口 |
| --- | --- | --- |
| MS1 基础与身份 | T01—T04 | 工程可启动；企业/成员/访客隔离；允许站点真实恢复访客身份 |
| MS2 可靠人工客服 | T05—T10 | 双窗口人工消息、认领/转交、离线留言、重试与重连真实可用 |
| MS3 知识与 AI | T11—T16 | FAQ/文本准备、自动回答、交接停发、试问、人工辅助可验证 |
| MS4 八模块收尾 | T17—T20 | 客户、工单、团队设置、统计完整且权限一致 |
| MS5 系统验证 | T21—T23 | 隔离、竞态、故障和真实模型评测有独立证据 |
| MS6 交付演示 | T24—T26 | Compose 部署/恢复、全量验收、演示和项目说明齐备 |

先读对应设计，再检查实际代码与任务完成记录。T01 已创建入口目录，其他路径按任务逐步建立；不能仅据规划路径声称功能已实现。任务状态以实际验证证据更新。

## 3 各任务交付与验收

### T01 工程、版本和本地环境

状态：已完成本地验收。应用启动、类型、lint、格式、构建、单元与 HTTP smoke 通过；Docker 实测 PostgreSQL 17.11、pgvector 0.8.7、Redis 8.8.4 连接成功，停启依赖的健康状态与恢复通过，本任务启动的服务已清理且数据卷保留。没有真实模型配置，能力验证明确保留未验证；业务迁移、浏览器业务 E2E 与完整部署由后续任务验收。

输入：主方案第 5/13/20/22 节、项目 AGENTS、质量规范。交付：实际兼容版本记录；pnpm workspace、Nuxt/Nest/FastAPI 最小工程；PostgreSQL+pgvector/Redis 本地依赖；TS/Python 锁与最小健康检查。模型/Embedding 型号与维度形成配置合同，有真实服务才做能力探针。

验收：记录实际安装版本与官方依据；三个应用最小启动/健康检查和空数据库连接通过；没有真实模型配置时明确标未验证；不得提前建聊天假闭环。脚本定义后记录 cwd、命令、退出码，停止仅由本任务启动的服务。

### T02 数据模型与迁移约束

状态：已完成本地验收。24 实体、两条可回放迁移、95 CHECK/61 FK/17 完整性触发器和合成种子已实现；58 项真实数据库断言通过，空库/重复部署/带数据升级/非法写入/Prisma 查询及索引计划均有证据。本地开发库已迁移，合成数据只进入隔离测试库并已清理。业务服务级并发、状态流转及真实 Embedding 能力仍由后续任务验收。

输入：[数据模型](data-model-v1.md)。交付：24 实体、索引、复合 FK、状态/身份检查约束、知识向量列、迁移与合成种子。Prisma 不支持的约束使用已核实版本的迁移扩展，不在另一处维护重复 schema。

验收：空库迁移、重跑种子、版本升级样本通过；跨组织关联写入失败；消息/任务/请求唯一键生效；备注不占消息 seq。禁止 db push 冒充可回放迁移。

### T03 账号、企业、成员与邀请

节点 N01；接口 A001—A014、A069；页面 P01/P02。交付：会话 Cookie、注册登录退出、组织选择/创建、两角色、邀请预览/接受/撤销/列表、最后管理员保护。新组织带默认 widget 配置。

验收：AT01/AT15/AT16 的身份部分；邀请并发消费只有一次，停用/退出后连接或请求失效，多标签企业选择不串上下文；密码/令牌不进入公开 DTO。成员停用后的会话补偿由 T08 完成，当前不能标整个 AT16 已通过。

### T04 跨站小窗身份与接入

节点 N01/N03；接口 A018—A021 和 A024 的访客资料部分。交付：加载脚本、iframe 握手、父站点第一方令牌保存/恢复、独立访客 Bearer、允许 origin、最小联系资料更新；P03 的身份外壳。

验收：两个不同 origin 同 publicKey 的凭据不串；禁止 origin 被拒；第三方 Cookie 被禁时正常恢复；存储不可用有明确体验；bootstrap 确认丢失/重复返回同一身份；相同邮箱不能冒认历史。AT01/AT13/AT14/AT15 对应部分。

### T05 会话与消息事务

状态：2026-11-07 本地验收通过；实际命令、增量迁移和边界见 [T05 说明](messages-development.md)。

节点 N03；A027—A029、A038—A040；数据 conversations/messages/receipts/outbox。交付：首消息原子建会话、seq、幂等请求、canonical Message、历史页与稳定水位、失败分类。

验收：AT20/AT21 数据层；同 ID 并发只一条，同 ID 不同正文 409；数据库失败不 ACK，重试已成功请求返回原结果；公开历史无备注；创建时间对应首消息，刷新不产生空会话。

### T06 outbox、Socket 与 HTTP 恢复

实施状态：本地服务端验收通过；Outbox、三项 Socket 操作、当前 ACL 投影、BullMQ 生产及 HTTP 恢复已实现，无迁移。前端归并/轮询仍归 T07，presence 归 T08；详见 [T06 说明](realtime-development.md)。

主方案节点 N03、AI 流程 Q12；交付：API 进程 outbox 投递、Socket subscribe/send/ACK/events、授权接收者重算、HTTP 备用发送、后台任务投递路径。队列 payload 只存定位 ID。

验收：AT20—AT23 服务端部分；确认丢失、广播先到、重复事件、进程恢复、Redis 不可用仍能 HTTP 发/查；发布后崩溃可重投而不产生重复业务效果。

### T07 前端消息状态与连接

状态：2026-11-07 本地验收通过。统一 API/Socket、身份代次、消息归并、连续水位恢复、单 HTTP 恢复循环和内存草稿隔离已实现；既有身份与跨站页面回归通过。完整聊天 UI 仍归 T09/T10，实测范围见 [T07 说明](frontend-development.md)。

输入：[前端规范](frontend.md)、API 第 4 节。交付：统一 API/Socket 客户端、连接生命周期、消息归并、初始 50 条/历史上翻/重连补拉、上下文隔离、草稿保护基础能力。

验收：AT21/AT22/AT27 对应部分；乱序和空洞正确补齐，历史分页不倒退实时游标；切企业/退出销毁旧监听，ACK 超时不是“确定未保存”；不得按相同文字去重。

### T08 交接、认领、成员在线与关闭

实施状态：指定 11 个 API、统一状态服务、Socket/HTTP 在线及管理补偿已实现，13 组真实隔离验收通过，详见 [接待说明](reception-development.md)。完整页面与自动发送消费者由后续任务承接。

节点 N06/N07；A015—A017、A030—A037。交付：统一状态 service、原子 claim、admin assign、transfer、close/reopen、在线心跳、成员停用补偿、AI 关闭后的等待状态、首次人工响应事实写入。

验收：AT05/AT09—AT11/AT16/AT19 的人工边界；两人认领仅一人成功；最后管理员不丢失；等待/人工重开不回 AI；HTTP 降级活动页面仍可更新接待可用性；关闭会话不改工单。

### T09 客服收件箱

页面 P04；接口 A028—A042。交付：三栏工作台、待接待/我的/全部授权列表、认领/转交/关闭、客户摘要、公开回复、独立内部备注、未读游标。AI 区域可先明确待实现，不用假结果占位。

验收：AT10/AT12/AT27 对应人工部分；失去分配权后不能写，备注不会出现在访客流；新事件不抢焦点，转交失败保留编辑内容并刷新状态。

### T10 访客聊天与真实演示入口

页面 P03/P10；复用 T04/T07/T08。交付：小窗四态、文本、显式转人工、离线留言/可选资料、关闭/新咨询、同凭据历史恢复；一个合成网站演示。

验收：AT09/AT13/AT19/AT22/AT27；无邮箱也可保存，已结束不接受新消息；真实客服双窗口交接可走通；没有 AI 前清楚显示人工路径，不能用预置回复冒充自动接待。

### T11 知识 CRUD、版本与启停

节点 N02；A043—A051。交付：两类输入、不可变正文版本、业务/准备状态、修改撤出可用集合、准备触发、启停/删除、knowledgeRevision 与审计。

验收：AT02/AT04 数据层；非 admin 不能编辑；非 ready 不能启用；编辑/停用后检索集合及时失效；历史来源快照所需版本保持可追溯。

### T12 AI 内部服务与可控提供方

接口 A067/A068；输入输出见 [AI 流程](ai-workflow-v1.md)。交付：FastAPI 内部服务认证、infer/embed Schema、单一模型提供方适配、超时/usage、fake provider 故障模式；不接业务 DB。

验收：有效/无效 JSON、额外执行字段、维度不符、限流、超时分别可观察；无外部凭据也可运行合同测试；真实提供方与 fake 的结果明确区分。

### T13 知识准备、Embedding 与检索

节点 N02/Q05；交付：切片/向量批处理、版本 lease、幂等 chunk、精确 top-5、租户/版本过滤、准备失败重试和失联修复。

验收：AT02/AT04/AT15；同版本重试不重复 chunk；不同租户相似问题不串来源；旧 worker 不把新版本标 ready；模型维度变更显式拒绝，不静默重用旧向量。

### T14 自动接待、超时与原子发送

节点 Q01—Q13；交付：answer task、连续输入失效、一次澄清、候选/source 校验、最终事务、交接系统提示、30 秒绝对期限、独立 DB 扫描器、非阻塞交接摘要触发。

验收：AT03—AT11/AT25 对应自动部分；转接/关闭/停用知识/AI 开关/新输入与生成并发时结果合法；过期消息数为 0；AI/Redis 故障不阻塞人工发送；不创建外部业务工具。

### T15 翻译、摘要与回复草稿

页面 P04；A053—A055。交付：原文/译文、覆盖范围摘要、内部草稿、来源查看、draftRevision、错误/重试、服务端输入版本验证。

验收：AT12/AT25/AT26；备注不进对客草稿；旧建议不覆盖人工编辑；生成任何辅助结果不自动新增公开消息；转交后原负责人不能读结果。

### T16 知识后台、试问与来源

页面 P05；A043—A055 的知识/试问路径。交付：列表/编辑、两状态展示、准备/失败重试、显式启用、试问结果和依据、受限 agent 只读模式。

验收：AT02/AT04/AT06/AT07；试问不建客户会话、不计统计、不向访客发送；保存已启用内容的影响清楚；agent 不能借筛选获取草稿或停用正文。

### T17 客户资料、搜索与授权历史

页面 P06；A022—A026。交付：客户后台 CRUD 范围内更新、姓名/邮箱检索、内部备注、会话/工单关联列表；复用 T04 访客字段校验，不复制规则。

验收：AT14/AT15；有客户权限不扩大到所有关联历史；相同邮箱不跨身份合并；匿名资料可处理；权限过滤在分页前执行。

### T18 工单完整闭环

节点 N08；页面 P07/收件箱建单；A056—A062。交付：建单、关联、优先级、负责人、四态、追加记录、解决/重开说明、并发版本、未解决同会话提醒。

验收：AT17—AT19；重复建单请求一张；改派限 admin；会话/工单独立；源会话无权时不泄漏历史；停用成员工单可重新指派。

### T19 团队与设置页面

页面 P09；复用身份/站点/在线/AI 开关 API 及 A069 邀请列表。交付：企业资料/时区、邀请/角色/停用、接待意愿与语言、域名/欢迎语、AI 状态与开关。

验收：AT01/AT11/AT16/AT26；最后管理员保护有清楚反馈；禁用 AI 现有会话转等待、重开仅影响新会话；模型凭据不在页面载荷。

### T20 指标聚合与统计页面

验收：AT24；使用跨日、重开、重复转接、未响应、已停用负责人样本手工对账；试问/备注/草稿不计入业务；null 与 0 区分，统计失败不返回伪造空值。

### T21 权限与租户负向验证

交付：覆盖全部业务端点、Socket 订阅/推送、知识检索/结果/来源的身份与资源访问矩阵，修复本任务范围内发现的问题。

验收：AT15/AT16/AT25；企业 A/B、admin/agent/visitor、转交前后、成员停用、邀请失效逐项验证；跨租户 FK 与应用服务两层都拒绝；错误和列表不能泄漏不可见资源。

### T22 并发、故障与恢复验证

交付：可控时间/事务屏障、ACK 丢失/乱序、Redis/AI/worker 故障、知识变化、重复消费和截止时间测试；记录实际 DB 状态与事件。

验收：AT05/AT08/AT20—AT23；硬失败数为 0；可以证明一个请求只产生一个业务效果；截止后迟到候选被丢弃，旧轮次故障不交接新轮次；人工 HTTP 路径不依赖 Redis。

### T23 AI 固定集与真实效果评测

交付：50 条合成评测样本、运行记录、模型/Prompt/知识配置绑定、人工评分与失败分析；对照 fake 故障用例单独报告。

验收：PRD 固定分组完整，知识内≥18/20 可接受；越权、虚构业务操作承诺、交接后自动回复为 0；未达标只调整当前检索/Prompt 并重跑受影响集，不隐藏失败样本或修改门槛冒充通过。

### T24 部署、健康检查与备份恢复

交付：应用 Compose/镜像、内部网络、迁移顺序、健康/降级状态、服务端配置说明、数据库备份/隔离恢复、回滚步骤。

验收：干净环境从文档启动；DB 断开 readiness 失败，AI/Redis 断开人工路径仍可用；恢复库能查询消息、工单和知识向量；不暴露 AI/DB/Redis 公网端口。仅部署到用户后续授权的目标。

### T25 完整验收、性能与可访问性

交付：AT01—AT27 逐项输入/操作/预期/实际/版本/证据，消息 100 样本时延、键盘/输入法/窄屏、演示走查和残余问题列表。

验收：八模块闭环、硬失败为 0；同一记录环境 p95≤2 秒；30 秒 AI 等待有人工路径；真实模型证据引用 T23，不重复用 mock 代替；未通过项不标 V1 完成。

### T26 项目说明与产品演示材料

交付：实际技术栈和目录说明、可复现启动命令、架构/取舍、合成数据说明、截图/演示步骤、验证结果和限制；说明关键技术决策及其适用边界。

验收：陌生开发者能依 README 运行演示；截图与版本对应；“已实现/已验证”有 T25 证据；没有虚构客户、营收、规模或线上性能。提交、推送、公开发布按用户届时指令。

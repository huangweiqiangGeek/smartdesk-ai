## 2 公共前端规则

Nuxt 页面负责装配，业务 API/Socket、错误映射与消息归并分别放 composable/service；跨页面仅共享身份上下文、当前会话缓存、连接生命周期和草稿。组件不直接访问数据库或模型。

T07 已提供上述基础客户端与既有身份页面装配，见 [实现与验证入口](frontend-development.md)。草稿仅在当前浏览器 app 内按身份/会话保留，刷新后不自动重发未知请求；这不代表 P04/P03 完整聊天界面已完成。

后台与小窗的私密数据在身份建立后客户端查询，不放模块级 SSR 单例；服务端渲染外壳时也不嵌入未授权聊天。切企业/退出/凭据失效，递增 contextGeneration、断开旧连接、清理对应缓存与草稿，迟到请求不能落到新企业。

每个列表具备加载、空、错误、重试；每个写入具备提交中、防重复触发、成功后回读/合并、422 字段错误、409 冲突和权限失效。列表失败不显示“0 条”；按钮隐藏只改善体验，不能承担授权。

文字消息默认安全纯文本渲染，允许受限链接；V1 不需要富文本编辑器。输入保留换行，中英文案按语言资源维护。Enter 发送、Shift+Enter 换行，输入法 composition 期间 Enter 不发送。

## 3 身份与企业入口

P01 注册填写邮箱、显示名、密码；成功建立后台会话并进入 P02。登录不返回敏感鉴权字段；错误提示清楚但不通过文案枚举账号。退出成功或 session 失效都清理当前连接。

P02 没有企业时显示创建入口；有一个企业可直接进入收件箱，有多个时选择。新企业进入设置引导：知识 → 启用与试问 → 网站域名 → 接入验证 → 添加客服。引导只组织已有功能，不额外增加 onboarding 状态平台。

邀请链接使用 /invite#token；浏览器取 fragment 后调用 A011/A012，不把 token 放服务端页面请求 URL。过期、撤销、已使用明确说明；已登录另一账号时可退出再接受，但不得在未经动作时替用户接受。

## 4 客户聊天小窗与演示

父站点 widget.js 只负责浮动入口、iframe 创建、尺寸/开关、第一方令牌保存及受限 postMessage。iframe origin 必须是配置的 SmartDesk 地址；双方同时校验 origin 和 source，不支持任意键的通用存储代理。

身份存储以 publicKey+父站点 origin 分区；只存访客令牌与过期信息，不把成员 Cookie 或模型凭据交给父站点。A020/A021 由父站点加载脚本请求，成功后保存并交给 iframe 内存；后续聊天请求由 iframe 发出。刷新由父站点恢复，不依赖第三方 Cookie。bootstrap 重试复用原 Idempotency-Key，窗口过期且未收到令牌时明确新建身份。存储不可用时仍能本次聊天，但提示关闭后可能不能恢复。

| 接待状态 | 标题/提示 | 允许操作 |
| --- | --- | --- |
| 首次进入 | 欢迎语与“AI 客服”或人工入口 | 首条消息原子建会话；空输入不可提交 |
| AI 接待 | AI 身份、处理中；没有未验证 token 文本 | 发消息、转人工、结束；有成功回答后可明确已解决 |
| 等待人工 | “已转人工，等待接待”；无人在线时说明稍后处理 | 继续补充、选填姓名/邮箱、结束；不承诺排队分钟数 |
| 人工处理中 | 人工身份及显示名 | 继续消息与结束；不自动恢复 AI |
| 已结束 | 历史只读、结果说明 | 新咨询创建新会话，不能继续向旧会话发送 |

转人工先显示提交中，服务端成功后切状态；失败不假报转接完成。消息 pending/sent/failed 以 ACK/查询为准，sent 只代表保存。ACK 超时先查 A040 或同 ID 重试，不生成新 ID。

未确认消息和草稿只在当前身份隔离的页面状态/sessionStorage 中按能力保留；没有恢复到原请求 ID 的刷新场景不能自动重发未知请求。先补拉已保存历史，缺失草稿不伪造成已发送内容。

P10 使用同一个加载脚本和真实 API，示例数据标为演示。客服入口只给导航说明；不能把管理员凭据嵌入公开页面或自动让访客获得后台身份。

## 5 客服收件箱

桌面三栏：左侧待接待/我的/全部有权会话；中间公开聊天与独立备注模式；右侧客户信息、交接摘要、关联工单。小屏改为列表、聊天、侧栏逐层切换，保留返回位置。

| 区域/动作 | 行为与数据源 | 关键错误与保护 |
| --- | --- | --- |
| 列表 | A028，状态/负责人/最后消息/未读；waiting 为未分配等待队列 | “全部”不是全企业权限；队列显示咨询必要信息，不连带开放完整客户档案 |
| 接管 | A031 原子 claim；admin 主动接管走 A032 指派给自己 | 409 提示已有人接待并刷新，不能继续以旧负责人发送 |
| 聊天 | A029/A039 与 Socket；显示原文和独立翻译 | 按 Message ID/seq 合并；历史上翻和重连游标独立 |
| 人工输入 | A038；只当前负责人可发送 | 失去负责人/关闭时保留本地草稿但禁发，刷新当前状态 |
| 内部备注 | 切独立输入模式 A041/A042，明显“仅团队可见” | 不混入公开消息，不触发自动回答，不用颜色作为唯一标识 |
| AI 草稿 | A053/A054；显示依据入口 A055 | 结果过期标注；draftRevision 不匹配禁止覆盖已编辑内容 |
| 交接摘要 | 当前历史摘要、未解决事项 | 失败仍展示原始历史并可人工接待；不遮挡主输入区 |
| 转交/结束/重开 | A033—A035；理由、当前版本、明确结果 | 结束提醒未解决工单仍保留；重开默认操作者人工接管 |
| 创建工单 | A056；标题/描述由当前客户内容预填可编辑 | 已有未解决工单时先提示查看，明确选择后仍可另建不同问题 |

未读游标只因当前成员实际查看并标记推进，计数按未读访客消息计算；新 AI/系统提示不冒充客户新问题。待认领队列数量与个人未读数量分开显示。

## 6 知识库

P05 列表显示类型、标题、业务状态、准备状态、更新时间；两种状态不得合成一个模糊“已发布”。admin 能创建/编辑/准备/启停/删除，agent 只读已启用资料与试问。

FAQ 表单为问题/答案，文本为标题/正文，按 PRD 长度与空白规则校验。点击保存已启用条目时提示“保存后暂停用于新回答，需要重新准备并启用”；仅打开编辑器或未保存输入不改变服务中的版本。

保存 → prepare 返回 202 → 轮询/事件展示 ready/failed → 明确点击启用。失败给稳定错误文案和重试，不能将部分 chunk 准备成功显示成整体就绪。

试问独立区域输入问题，展示自然语言结果、answer/clarify/handoff、引用标题/片段/版本；注明“不会创建客户会话”。准备或试问加载时可以离开，回来通过服务端状态恢复，不能依赖某个页面组件仍存活。

删除前先停用并确认；历史对客回答仍可查看授权的来源快照。版本列表仅 admin，不提供 PDF/URL 导入按钮。

## 7 客户与工单

P06 按姓名/邮箱搜索，客户详情包括可编辑基础资料、内部备注、授权范围内的会话和工单。无联系方式显示匿名，不要求补齐才能处理。相同邮箱不自动合并，客户可见不代表其全部关联记录可见。

P07 为列表+详情。列表可筛状态/负责人/优先级；详情包含描述、关联客户/会话、处理记录和状态动作。agent 只能看自己负责工单；admin 可看全部和改派。指派给已停用成员的历史工单显示“待重新指派”，仍计未解决。

已解决需要处理说明，重开必填原因；版本冲突保留本地输入并展示服务器当前版本，操作者决定重提。处理记录追加，不覆盖历史。

工单负责人可能没有原会话读取权限：展示已有工单描述和客户允许信息，源会话链接显示权限限制，不通过关联工单隐式放开完整聊天。会话和工单的状态按钮互不代替。

## 8 统计与设置

P08 admin 显示 PRD 的六类指标；agent 显示本人首次回复工作量、响应均值与当前待处理工单。选择今天/近 7 天/近 30 天/自选日期，明确企业时区；快照工单量单独标记。averageMs=null 显示暂无样本，不能画成 0 秒。

P09 企业设置维护名称/时区，成员页通过 A069 读取邀请状态并支持撤销；邀请链接只在创建成功时显示，丢失可撤销后重建，列表不恢复原 token。最后管理员操作失败明确原因。个人可接待开关结合后台活动页面心跳，不把“手动设为在线”当作连接一定存在。

网站设置复制公开加载信息并维护精确 origin；接入测试使用真实小窗。AI 设置显示开关、当前可用知识和服务能力状态；服务恢复不自动使人工会话回到 AI。模型凭据属于服务端部署配置，不在企业浏览器表单录入。

## 9 页面验收

每页以可用真实接口或明确测试替身驱动，交付时区分两者。验证未授权访问、空/错误/加载/提交/冲突、键盘与输入法、小窗窄屏、切企业无旧数据、草稿保护和断线恢复；截图只是 UI 证据，不能替代消息/权限断言。
